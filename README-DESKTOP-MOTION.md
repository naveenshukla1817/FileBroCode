# Desktop Section Motion Update

This update adds subtle, theme-matched motion to the desktop-app feature section:

- The feature card lifts very slightly on hover.
- The File bro code desktop preview grows gently and tilts toward the pointer.
- Preview internals reveal in small staggered steps when the section enters the viewport.
- Benefit items appear sequentially instead of popping in together.
- The preview has a restrained idle float for a livelier page.
- Three macOS-style traffic-light dots were added to the preview header. They stay muted until hover, then reveal red/yellow/green accents.
- Reduced-motion preferences disable the animations.
