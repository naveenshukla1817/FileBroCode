# Desktop download UI changes

- Removed the navbar Download App button.
- Added a neutral monochrome Windows icon to desktop download buttons.
- Removed green accents, green borders, and green glow effects from desktop download buttons.
- Kept the desktop feature section above the existing footer content.
- Desktop feature section now follows the same charcoal/gray visual language as the site.

The desktop installer URL remains configurable with `NEXT_PUBLIC_DESKTOP_DOWNLOAD_URL`, defaulting to `/downloads/FileBro-Setup-1.0.0-x64.exe`.
