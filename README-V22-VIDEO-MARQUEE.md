# FileBroCode v22 — Video-referenced File Marquee

The supplied 10-second reference video was inspected frame-by-frame. This revision adapts its visible motion language to the existing FileBroCode hero: a dense, calm field of recognizable file logos travels along varied curved/diagonal trajectories on the right side, rather than using visible concentric orbit rings.

- Multiple file logos are visible at once, with varied paths and staggered timing.
- Icons remain upright and recognizable.
- Icons scale subtly and fade at the travel boundaries, allowing an invisible re-entry.
- No individual logo card, pill, rectangular background, or orbit-line decoration is used.
- The existing dark/grey FileBro visual system remains intact.
- Motion is SVG-native and does not use a React per-frame render loop.
- `prefers-reduced-motion` shows a static fallback set of file icons.
