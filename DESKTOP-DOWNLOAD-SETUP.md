# Desktop download setup

The UI is wired to `NEXT_PUBLIC_DESKTOP_DOWNLOAD_URL`. If the variable is not set, the buttons use:

`/downloads/FileBro-Setup-1.0.0-x64.exe`

Place the Windows installer at `public/downloads/FileBro-Setup-1.0.0-x64.exe`, or set `NEXT_PUBLIC_DESKTOP_DOWNLOAD_URL` to a hosted installer URL.

The supplied installer is the `FileBro-Setup-1.0.0-x64.exe` build provided alongside this source package.
